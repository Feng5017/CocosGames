# CocosGames

基于 C++ 与 Cocos2d-x 的个人游戏项目合集，保留游戏源码、资源、工程配置及各项目自带的引擎依赖。

## 项目导航

| 目录 | 内容 |
| --- | --- |
| `CatElim/` | 三消游戏：交换相邻图块、匹配消除、下落补齐，包含步数与限时关卡 |
| `Plane/` | 飞机射击游戏项目 |
| `Catpop/` | Cocos 动画效果演示，包含翻转与波浪效果 |
| `2048/` | 2048 项目目录 |
| `Text/`、`Text2/`、`ZhongJialong/` | 其他历史项目，保留原始目录名称 |

## 目录结构

各项目维持原工程布局，便于保留相对路径引用：

- `Classes/`：C++ 游戏代码。
- `Resources/`：图片、音频等游戏资源。
- `proj.win32/`：Windows Visual Studio 工程。
- `cocos2d/`：项目自带的 Cocos2d-x 引擎和第三方依赖。
- 其他平台工程与 `CMakeLists.txt`：按原项目保留。

多个项目的引擎文件存在重复；保留各自依赖以兼容原工程，完全相同的文件由 Git 对象存储去重。

## 构建说明

`CatElim` 与 `Catpop` 已确认使用 Cocos2d-x 3.17、C++ 和 Windows 32 位工程，无需 Cocos Creator。
使用 Visual Studio 打开对应 `proj.win32/` 下的解决方案；旧工程可能需要安装对应 C++ 工具集，或重定向工具集与 Windows SDK 后处理兼容性问题。

原始备份中的现成 EXE 曾通过启动验证；本仓库排除了生成的 EXE 所在构建目录，整理后的源码尚未重新编译验证。运行时需确保资源路径与工程配置一致。

## 收录范围

- 收录：游戏代码、资源、项目配置、随项目附带的引擎及第三方依赖。
- 排除：Visual Studio 缓存、编译中间文件、Debug/Release 构建输出，以及独立 Tiled 编辑器。
- 首次整理保留 30,143 个项目文件，未压缩约 2.49 GB；当时 Git 对象包约 176 MiB。

第三方引擎及依赖的许可文件随原目录保留，使用和分发时请遵守各自许可。
